# HomeSocks

HomeSocks 是一款将公共 VPN 节点（如 VPN Gate 家宽节点）转化为标准 SOCKS5 代理的出口网关工具。它通过 Linux 网络命名空间（Network Namespace）技术隔离 OpenVPN 进程，确保在不污染宿主机全局路由表的前提下，为您提供纯净、可动态切换的 SOCKS5 出口。

本项目设计极简、零外部运行库依赖（提供静态编译二进制文件），并内置了 Web 可视化控制面板。

## 核心原理

1. **物理隔离 (Network Namespace)**
HomeSocks 在宿主机中创建隔离的网络命名空间（如 `hs-netns`），并在该命名空间内运行系统级 `openvpn` 客户端。这使得 OpenVPN 下发的全局路由表仅在该独立空间内生效，绝不会切断或影响宿主机本身的 SSH 连接与网络请求。
2. **按需拨号 (Setns)**
SOCKS5 服务端默认监听在宿主机网络栈。当接收到客户端请求时，服务端会锁定当前系统线程（`runtime.LockOSThread`），并利用 `setns` 系统调用将当前线程切入至隧道所在的命名空间，建立目标连接后再切回宿主机。
3. **零感知真连接测速 (Shadow Test)**
为了在不中断当前主隧道的情况下测速候选节点，系统会在后台动态创建临时的命名空间（如 `hs-test-xxx`），并在其中发起连接测试。一旦测试成功并判定为更优节点，主环境才会进行平滑切换。

## 产品特性

* **纯净 SOCKS5**：仅对外暴露单一标准 SOCKS5 端口（MVP 阶段支持 TCP CONNECT）。
* **Web 可视化面板**：内置纯静态无外部请求的轻量级 Web 面板，可查看节点列表、当前连接状态、测速并切换节点。
* **自动化节点池**：利用 GitHub Action 每天自动从 VPN Gate 抓取并过滤优质住宅宽带节点，项目内置同步机制。
* **国家优先级寻优**：支持设置国家优先级（如 JP, KR），断线或启动时自动按优先级寻找最优节点。
* **死锁模式**：支持手动在面板选定单一 IP，后台状态机将进入锁定模式，即使断线也仅尝试原节点重连，拒绝越权切换。

## 部署环境要求

* **操作系统**：Linux (推荐 Ubuntu, Debian, Alpine)
* **权限要求**：必须具备 `root` 权限。
* **内核特性**：支持 Network Namespace (`ip netns`)。
* **设备权限**：宿主机必须开放 `/dev/net/tun`。若使用 LXC 或 Docker，需确认母机是否下发了相关权限。

## 安装与配置

本项目提供高度自动化的一键安装脚本。

执行以下命令即可自动检测架构、安装依赖包（iproute2, openvpn 等）、拉取最新二进制文件并配置 systemd 守护进程：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Sparklewink/HomeSocks/main/install.sh)

```

安装完成后，终端会打印出：

1. Web 控制面板的访问地址（包含防扫描的随机路径）
2. 面板登录口令
3. SOCKS5 端口与认证账密

## 交互式终端工具 (hs)

安装完毕后，系统中将自动生成交互式管理菜单。您只需在终端输入以下命令：

```bash
hs

```

菜单包含以下功能选项：

* 1: 查看运行状态（服务是否存活、当前选路模式、当前出口 IP）
* 2: 找回面板密码与地址
* 3: 查看实时日志 (journalctl 持续输出)
* 4: 重启服务
* 5: 停止服务
* 6: 启动服务
* 9: 彻底卸载

## Web 面板使用说明

在浏览器中打开安装时分配的面板地址，输入口令即可登录。

### 面板主要功能

* **出口状态监控**：实时展示当前路由模式、使用的家宽节点 IP 以及真连接测速延迟。
* **总开关与模式切换**：可随时关闭 SOCKS5 代理，或将其从“隧道”切换为“直连”（走宿主机网络）。
* **优先级设置**：通过逗号分隔输入国家代码（如 `JP, KR, US`），保存后系统将严格按照此顺序自动寻找最优节点。
* **节点锁定**：在下方节点列表中，点击具体节点的“锁定”按钮，系统将切换为手动模式，强行绑定该 IP 出口。
* **恢复自动寻优**：点击“开启自动寻优”，解除手动锁定状态，交由后台状态机自动测速维护。

## 卸载

如果您不再需要 HomeSocks，可以通过 `hs` 交互菜单输入 `9` 进行安全卸载，或者直接运行系统内置的卸载程序：

```bash
homesocks-uninstall

```

该脚本将停止守护进程、清理二进制文件与配置文件，并销毁遗留的所有网络命名空间（netns），确保将系统恢复至安装前的绝对干净状态。
